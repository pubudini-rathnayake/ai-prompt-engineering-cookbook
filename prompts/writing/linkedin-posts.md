# LinkedIn Post Prompts

Prompts for writing engaging LinkedIn posts as a tech student or developer.

---

## Project Launch Post

```
Write a LinkedIn post announcing my new project with these details:

Project name: [name]
What it does: [one sentence description]
Tech stack: [list technologies]
Key features: [2-3 bullet points]
What I learned: [main learning]
GitHub link: [url]

Tone: Confident, authentic, relatable for tech students.
Length: 150-200 words.
Include 3-5 relevant hashtags at the end.
```

---

## Learning Milestone Post

```
Write a LinkedIn post about this learning milestone:

What I learned: [topic/skill]
How long it took: [timeframe]
How I learned it: [resources/method]
How I applied it: [project or use case]
Advice for others: [one tip]

Tone: Inspiring but humble. First person.
Length: 100-150 words.
End with a question to encourage engagement.
```

---

## Job Seeking Post

```
Write a LinkedIn post indicating I am open to opportunities
with these details:

My background: [degree, university, year]
Skills: [list top 5 skills]
Project experience: [briefly mention 2 projects]
Type of role I am looking for: [role type]
Location preference: [remote/hybrid/location]

Tone: Professional and enthusiastic.
Do not sound desperate. Focus on value I can bring.
```
