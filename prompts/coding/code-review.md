# Code Review Prompts

Ready-to-use prompts for getting high-quality code reviews from AI.

---

## General Code Review

```
Review the following [language] code as a senior software engineer.
Check for:
- Security vulnerabilities
- Performance issues
- Code readability and maintainability
- Best practices and design patterns
- Any bugs or edge cases

Code:
[paste your code here]
```
