# Debugging Prompts

Prompts to help you find and fix bugs faster with AI assistance.

---

## General Debugging

```
I have a bug in my [language/framework] code.

Error message:
[paste error here]

Code:
[paste your code here]

What I have already tried:
[list what you tried]

Please identify the root cause and provide a fix.
```

---

## CORS Error (Spring Boot)

```
I am getting a CORS error in my Spring Boot + React application.

Error: [paste error]
Security config: [paste SecurityConfig.java]
Controller: [paste controller]

Identify the exact cause and give me the corrected configuration.
```

---

## 500 Internal Server Error

```
My API returns a 500 Internal Server Error for this endpoint.

Endpoint: [method + path]
Request body: [paste request]
Stack trace: [paste stack trace]
Relevant code: [paste code]

Walk through the stack trace step by step and tell me
exactly what is failing and why.
```

---

## Database / JPA Issue

```
I have an issue with my Spring Data JPA query.

Expected behaviour: [describe]
Actual behaviour: [describe]
Entity class: [paste]
Repository method: [paste]
Error (if any): [paste]

Diagnose the problem and suggest a fix.
```
