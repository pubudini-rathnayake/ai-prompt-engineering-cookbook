# Study Plan Prompts

AI prompts to help students create structured, personalized study plans.

---

## Weekly Study Plan

```
Create a detailed weekly study plan for the following:

Subject: [subject name]
Current level: [beginner / intermediate / advanced]
Available study hours per day: [hours]
Days until exam/deadline: [number]
Topics to cover:
- [topic 1]
- [topic 2]
- [topic 3]

Include daily goals, recommended resources, and revision days.
Format as a day-by-day schedule.
```

---

## Topic Deep Dive

```
I need to learn [topic] deeply in [timeframe].

My current knowledge: [describe]
My goal: [what you want to be able to do]

Create a structured learning path with:
1. Prerequisites to review
2. Core concepts in order
3. Hands-on practice tasks
4. Resources (free preferred)
5. How to know when I have mastered it
```

---

## Exam Preparation

```
Help me prepare for my [subject] exam in [days] days.

Topics on the exam:
[list topics]

My weak areas:
[list weak areas]

Create a revision schedule that prioritizes my weak areas
while covering all topics. Include daily tasks and
self-assessment checkpoints.
```
