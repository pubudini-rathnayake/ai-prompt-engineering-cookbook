# Contributing to AI Prompt Engineering Cookbook

Thank you for your interest in contributing!

## How to Add a Prompt

1. Fork this repository
2. Navigate to the relevant category folder under `prompts/`
3. Add your prompt to the existing `.md` file or create a new one
4. Follow the existing format (Template + Example + Tips)
5. Submit a pull request with a clear description

## Prompt Quality Guidelines

- Every prompt must include a clear Template
- Include at least one real Example
- Add Tips where relevant
- Test your prompt with at least one AI model before submitting
- Keep language clear and beginner-friendly

## Adding a New Category

If your prompt doesn't fit any existing category, create a new
folder under `prompts/` and open a pull request explaining
the new category.
