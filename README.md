## 🚀 Quick Start

Just browse to the category you need and copy the prompt template. Replace the `[bracketed]` placeholders with your own content.

**Example — Debug your code in seconds:**

```
I have a bug in my FastAPI code.

Error message: 422 Unprocessable Entity
Code: [paste your code]
What I already tried: Checked the request body format

Please identify the root cause and provide a fix.
```
